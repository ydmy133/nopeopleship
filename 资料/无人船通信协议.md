# 无人船通信协议

船端与上位机之间传 UTF-8 JSON。坐标系为 WGS84。

船端物理口为 UART4：115200，8 数据位，无校验，1 停止位。一帧指令必须是单个 JSON 对象，首字符为 `{`，末字符为 `}`，后面不能再带换行。遥测发出去时，JSON 后面带 `\r\n`。单帧不超过 512 字节。

## 1. 上位机下发

除 `control_mode` 外，下面字段都必须带上。缺任一字段时本帧丢弃，船保持上一拍指令。未带 `control_mode` 时按 `manual` 解析。

```json
{
  "control_mode": "manual",
  "move_speed": 0,
  "steer_speed": 0,
  "target_lat": 0.0,
  "target_lon": 0.0,
  "return_lat": 0.0,
  "return_lon": 0.0,
  "dc_prot": 1,
  "lb_prot": 1
}
```

| 字段 | 类型 | 范围 | 说明 |
| --- | --- | --- | --- |
| control_mode | string | 见下表 | 控制模式 |
| move_speed | int | -100~100 | 行进指令。解析允许负值，执行时前进量小于 0 会钳成 0，船不倒车 |
| steer_speed | int | -100~100 | 转向。正为左转，负为右转。只在 `manual` 直接打到舵 |
| target_lat | double | -90~90 | 目标纬度，度 |
| target_lon | double | -180~180 | 目标经度，度 |
| return_lat | double | -90~90 | 返航纬度，度 |
| return_lon | double | -180~180 | 返航经度，度 |
| dc_prot | int | 0 或 1 | 1 为使能断连返航 |
| lb_prot | int | 0 或 1 | 1 为使能低电量返航 |

当前模式不用的坐标填 `0.0`，不用的速度填 `0`。`return_lat` / `return_lon` 每帧都带，断连和低电量返航用最后一帧成功解析到的返航点。

闭环模式里的航速取 `move_speed` 的绝对值，记为滑条百分比。滑条 100% 对应约 1 m/s。

| 值 | 模式 | 行为 |
| --- | --- | --- |
| manual | 手动 | `move_speed` 为油门 0~100，`steer_speed` 为舵 |
| navigate | 点到点 | 从当前点驶向 `target_lat` / `target_lon`。进入 2 m 圈后推力归零并切回手动。同一目标再次下发不再启动 |
| stable_anchor | 稳泊 | 锚点为进入瞬间的船位，圈内保持进入时的艏向。不使用 `target_*`。出 2 m 圈后船头朝锚点前进回推 |
| cruise_speed | 定速巡航 | `move_speed` 直接当油门，舵固定为 0。不读对地速度，不锁航向 |
| cruise_dir | 定向巡航 | 锁定进入瞬间的艏向。滑条百分比走速度环，100% 约 1 m/s。不纠正侧向位置 |
| track_hold | 航迹保持 | 以进入瞬间的船位和艏向生成前方直线，沿地面贴线。靠近末端时航段向前延长，不因远处航点到圈而结束 |

`navigate` 与 `track_hold`：滑条为 0 时用默认航速 0.6 m/s；滑条大于 0 时取「滑条对应速度」和 0.6 m/s 中较小的一个。航行中只改滑条，不重新锁航向、不重置航段。

`stable_anchor`、`cruise_dir`、`track_hold` 只在模式切换时锁锚点或艏向。同一模式连续下发只更新速度（稳泊不看滑条）。

`navigate` 在模式切换或目标经纬度变化时重新进入。

## 2. 船端上报

对应 `main.c` 的 `System_UpdateTelemetry()` 与 `protocol.c` 的 `Protocol_PackTelemetryJSON()`。每 200 ms（`TELEMETRY_SEND_INTERVAL_MS`）发一帧，JSON 后跟 `\r\n`。

经纬度只报原始 GNSS，不做滤波。不上报横滚、俯仰、海拔。已废弃：`filt_lat` / `filt_lon` / `roll` / `pitch` / `altitude` / `dev_lat` / `dev_lon`。

```json
{
  "data_valid": 1,
  "heading_valid": 1,
  "battery_valid": 1,
  "gnss_status": 0,
  "heading_status": 0,
  "nav_reached": 0,
  "heading": 12.30,
  "battery_level": 0,
  "speed": 0.35,
  "gnss_yaw": 15.20,
  "gz": -1.80,
  "raw_lat": 31.2304000,
  "raw_lon": 121.4737000,
  "target_lat": 31.2304160,
  "target_lon": 121.4737010,
  "dist_error": 8.20,
  "heading_error": -4.50
}
```

| 字段 | JSON 精度 | 单位 | 代码来源 | 说明 |
| --- | --- | --- | --- | --- |
| data_valid | 整数 | — | `s_gnss_valid` | 1=GNSS 有效，0=无效 |
| heading_valid | 整数 | — | `s_heading_valid` | 1=最近 500 ms 内成功读取航向帧，0=无有效航向 |
| battery_valid | 整数 | — | `s_battery_valid` | 1=BMS 至少成功读取过一次，0=尚未成功 |
| gnss_status | 整数 | — | `GNSSSensor_Status_t` | 0=正常，1=发送失败，2=未收到数据/接收失败，3=长度不足，4=未找到合法帧头，5=CRC错误，6=尚未采样或上层超时，7=帧正确但尚未定位 |
| heading_status | 整数 | — | `HeadingSensor_Status_t` | 0=正常，1=发送失败，2=未收到数据/接收失败，3=长度不足，4=未找到合法帧头，5=CRC错误，6=尚未采样或上层超时 |
| nav_reached | 整数 | — | `s_boat.arrived` | 1=点到点已进入 2 m 圈；稳泊 / 定向 / 航迹保持为 0 |
| heading | `%.2f` | ° | `s_heading.yaw` | 航向传感器艏向，0 为正北，顺时针 |
| battery_level | `%.0f` | % | `s_battery_level` | BMS 剩余电量 0~100；主循环每 1 s 读取一次 |
| speed | `%.2f` | m/s | `s_gnss.speed / 3.6` | GNSS 地速由 km/h 换成 m/s |
| gnss_yaw | `%.2f` | ° | `s_gnss.yaw` | GNSS 对地航迹向，不是船头艏向 |
| gz | `%.2f` | °/s | `s_heading.gz` | 航向角速度，逆时针为正 |
| raw_lat | `%.7f` | ° | `s_gnss.latitude` | GNSS 纬度 |
| raw_lon | `%.7f` | ° | `s_gnss.longitude` | GNSS 经度 |
| target_lat | `%.7f` | ° | `s_boat.target_lat` | 点到点 / 返航目标，或稳泊锚点；手动与定速巡航为 0 |
| target_lon | `%.7f` | ° | `s_boat.target_lon` | 同上 |
| dist_error | `%.2f` | m | `s_boat.distance_m` | 到目标或锚点的距离；定向巡航为 0 |
| heading_error | `%.2f` | ° | `s_boat.heading_error_deg` | 期望艏向减当前艏向，范围约 ±180 |

## 3. 方向约定

艏向 0° 为正北，顺时针增加：90° 东，180° 南，270° 西。

`move_speed` 正值为沿船头前进。负值被钳成 0。

`steer_speed` 正值为左转，负值为右转。

## 4. 保护

### 断连

超过 5200 ms 没有解析成功的新指令，视为断连。

`dc_prot` 为 1：以最后一帧的 `return_lat` / `return_lon` 做点到点返航。收到新指令后退出返航，改执行该指令。

`dc_prot` 为 0：切回手动，推力归零。

### 低电量

`lb_prot` 为 1，且 `battery_level` 大于 0、小于 10：以返航点做点到点返航。保护期间忽略普通指令。

到达返航点后退出保护，推力归零。

强制退出：下发一帧 `move_speed` 等于 20。这一帧只解除保护，不执行其中的模式和速度。下一帧才按新指令走。

### 传感器异常

GNSS 或航向连续失败超过 3 次：停桨，切回手动，并退出断连返航和低电量返航。

点到点、稳泊、定点、航迹在定位无效时停桨。定向巡航只要求航向有效。
