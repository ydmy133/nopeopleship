# 通信和诊断

命令 UART4 115200 8N1；原 JSON 字段、模式字符串及数值范围保留。新增分包/连包及字符串转义分帧支持。最长 JSON 511 字节（另 1 字节终止符），未闭合对象最长 500 ms 后丢弃，接收环 2048 字节，解析 FIFO 8 项，cJSON arena 8192 字节，解析嵌套上限 16。rx_* 直接反映最近成功解析的原始命令；有效模式和实际发送输出分别记录。

队列满、接收环溢出或 UART 接收错误触发停止，清积压；后续有效命令解除故障，但已锁存零输出须成功发送。命令 timeout 为年龄严格大于 5200 ms；年龄 -1 表示从未接收有效命令。发送完成时刻后才更新实际输出。

新增遥测：output_status（0 完成、1 TX 失败）、output_valid、output_sent_ms；gnss_diag.v=7，其他原诊断字段保留。output_valid 说明曾完成发送，不证明电机执行。

rtos_diag.idle_pct 为上一采样区间 CPU 空闲百分比；stack_free 按“健康、控制、驱动、命令、GNSS、航向、BMS、遥测”排列，单位字节；errors 按“UART 恢复错误、接收溢出、传感器超时、命令队列/接收故障、JSON 错误、TX 错误”排列。统计首个区间仅供启动观察，台架用稳定运行后的区间。

USART6 9600 8N1，报文 `55 00 00 00 move steer 00 00 AA`；两个速度字段是有符号 8 位值。普通目标保留最新值，停止另行锁存。
